# 定制分支：v5–v7 源码迁移

> 本页为中文说明；行为以[英文源规格](/spec/03-runtime/custom-source-migrations)和当前源码、测试为准。

本规格只面向 `custom/main`，不改变数据库持久化格式，也不代表旧补丁安装包已由当前源码重新构建。

## 同模型 OAuth 账号回退

- 只在当前厂商、准确模型 ID、请求模型、端点、协议、能力和自定义头兼容的已启用 OAuth 账号之间轮换，不使用 API Key、无认证或扩展代理账号。
- 桌面宿主通过已有授权边界解析账号；启动载荷不携带长期凭据。只有耗尽限流恢复重试后才切换账号，不因认证、参数或本地准备错误轮换。
- 每个账号保留原有请求与十次重试预算，一次用户运行最多访问各账号一次；工具结果不重放，模型和上下文不变。
- 有限模式耗尽后报错；无限模式先尝试备选，再在最后账号继续可取消的原有重试。删除、禁用或修改账号池会退休空闲运行时，不能沿用已移除授权。
- 子代理保持显式模型和回退策略，不新增隐式模型覆盖或委派权限。

## 中文 `@` 子代理补全

- 只查询当前项目已安装、启用的定义；中文别名不会自动安装或启用角色，稳定英文 ID 保持可搜索。
- 选择后插入明确的本地化文本指令，不是文件引用、直接执行器或特权命令；Agent 模式和工具、模型权限仍生效。
- 文件、斜杠、插件补全及输入法、键盘导航和关闭行为不变；过期项目目录响应不得覆盖新状态。

## 完整便携自动化打包

包内包含当前分支的配额插件与授权助手，以及经验证的 Python、Node、浏览器运行时；不从账号文件旁、开发盘或系统虚拟环境执行代码。缺少运行时必须拒绝构建，不能静默输出仅源码的“完整包”。

账号、令牌、浏览器资料、可编辑 Python 安装、生成运行时和缓存不得进入 Git。插件仍须显式确认 `models.usage` 权限。

## 自用 macOS arm64 包

M2 等 Apple Silicon 使用原生 arm64 runner 构建 DMG/ZIP，包含可搬移 Python 3.12、原生 Node 与对应 Playwright Chromium。Windows 资源布局保持不变。Mac 从 `Contents/Resources/codex-automation` 发现资源，不要求目标机安装开发环境。

构建仅展开批准根内的链接，保留可执行权限，并在最终包中核对完整性清单。搬移到中文、空格目录以及挂载 DMG 后，必须通过离线账号校验、Chromium 和 Node 探针。包采用无需开发者证书的本地签名，不做 Apple 公证；只上传有保留期限的 Actions 产物，不发布官方标签。安装、单应用允许打开及手动更新说明见仓库的 `custom/MACOS.md`。

## 验收

账号回退须覆盖兼容性、遍历预算、取消、用量归属和授权失效；补全须覆盖中文、英文、过期目录、输入法与键盘/鼠标操作。打包须覆盖白名单、链接逃逸、缺失文件、跨目录搬移及插件权限/许可证。

不使用真实账号、付费厂商或用户正在运行的应用作为测试夹具。真实 OAuth 登录与第二台机器安装仍是独立验收项。
